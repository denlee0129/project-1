# Первый Python-проект

## 1. Описание проекта

Это мой первый Python-проект. Он демонстрирует работу с виртуальным окружением, установку зависимостей и загрузку переменных окружения из файла `.env` с помощью библиотеки `python-dotenv`.

Программа проверяет наличие обязательных переменных и сообщает об ошибках, если настройки отсутствуют.

## 2. Установка проекта

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
```

### Шаг 2. Переход в папку проекта

```bash
cd project-1
```

### Шаг 3. Создание виртуального окружения

```bash
python3 -m venv .venv
```

### Шаг 4. Активация виртуального окружения

Для macOS и Linux:

```bash
source .venv/bin/activate
```

### Шаг 5. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 3. Настройка переменных окружения

Создайте файл `.env` на основе шаблона `.env.example`:

```bash
cp .env.example .env
```

Откройте файл `.env` и заполните необходимые переменные:

- `APP_NAME` — название приложения.
- `API_KEY` — секретный ключ приложения.

Обе переменные обязательны для запуска программы.

**Важно:** файл `.env` содержит конфиденциальные настройки. Не загружайте его на GitHub.

## 4. Запуск программы

Для запуска выполните команду:

```bash
python main.py
```

## 5. Пример успешного вывода

```text
APP_NAME: DenisProject
API_KEY loaded: True
```

Если обязательная переменная отсутствует, программа выведет сообщение об ошибке.

Например:

```text
Error: API_KEY is missing
```

В таком случае программа завершится с кодом `1`.

## 6. Используемые библиотеки

- `python-dotenv` — загрузка переменных окружения из файла `.env`.
- `requests` — выполнение HTTP-запросов.
